# Current architecture audit

Baseline: Azure engineering commit8d4a6b5fdcd9f236cc6e9ade7a0bc093603b773f. The existing browser is a four-step HTML/CSS/JavaScript application in web/static. The browser contains no trained model. Relative GET /api/health, GET /api/examples and POST /api/predict requests are served by the same host as the page. Vercel currently deploys a Python FastAPI function and original fitted RF E4 artifact; Azure independently deploys the same runtime and model. This is two server-side inference deployments, not browser inference.

FastAPI caches the hash-verified original model, validates four electrical inputs, runs the unchanged fitted pipeline and multiclass argmax, then returns class/label/category/warnings/model identity. Class4 is environmental shade. Health loads/verifies the model; examples return five predetermined measurements. Charts/illustrations are input/selected-intent visualizations. Explanatory text is a predefined class-specific presentation selected only after the actual backend prediction; it is not a separate classifier or causal/model-attribution computation.

No CORS middleware is present. The existing CSP has connect-src self. Vercel configuration selects the FastAPI framework and packages Python/model files. Existing JavaScript uses a60-second prediction timeout and an unbounded one-off health request. Azure's API contract can support every frontend operation, but cross-origin browser access needs explicit-origin CORS and exposed timing/identity headers. The observed56.94-second scale-from-zero request motivates bounded startup handling separate from normal inference.

The implementation will reuse one canonical web/static asset source, build an allowlisted static-only Vercel output, configure a public Azure API base, and add an outer Azure CORS adapter without changing the inference implementation. The existing Vercel production deployment, original Azure revision/image, submission tag and scientific artifacts remain rollback/protection points. Vercel production cutover requires separate approval after preview verification.
