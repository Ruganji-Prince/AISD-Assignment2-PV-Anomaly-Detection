# Prior test exposure and evaluation limitations

The approved test partition was evaluated during an earlier legacy implementation. Consequently, the partition cannot be described as pristine or previously unseen. Earlier exposure is a methodological limitation that cannot be reversed by a new evaluation script.

Revised Stage 1 model settings and Stage 2 sensor/configuration decisions were selected using TRAIN and VALIDATION block 13. Stage 3 retained the explicitly approved LR F6, RF E4 and LightGBM E4 candidates. Hardware-alert thresholds were selected exclusively on VALIDATION block 14 and frozen, with hashes and a timestamped receipt, before the revised final test evaluation. No revised model, sensor, feature or threshold decision was based on earlier test outcomes within the recorded revised workflow; revised selection code does not load legacy test results. This statement describes the documented decision process. Software checks cannot independently establish the absence of influence from earlier human exposure.

No post-test tuning, threshold adjustment or candidate replacement was performed. The two frozen F6 tree-family reference evaluations support only same-family test Delta_s calculations. No claim of unbiased prospective generalization or external validation follows from this reused test partition.

The observations remain source-position ordered. The MAT release and exported CSV contain no explicit timestamp. Nominal 1 Hz acquisition, per-second electrical RMS calculations, one-second irradiance/temperature averages and the reported 16-day experiment do not establish calendar timestamps or uninterrupted spacing in the export. The 16 signal-defined blocks are not verified days, sessions or hours. The separator remains irradiance below 100 W/m² for at least 3,600 consecutive source positions, without labeling those positions as an hour. No source index or block identifier is a predictor; no alerts-per-hour or seconds-to-detection metric is reported.

The full primary population is retained, including low-irradiance observations. The 515,958 observations with irradiance >= 100 W/m² reproduce every paper-reported class count exactly; the paper's explicit use of that filter remains unverified. No post-hoc population filtering was introduced.

Natural building shade is an environmental state, not a hardware failure. Class recalls describe five-class argmax classification. Hardware-alert recall describes a separate threshold applied to p1 + p2 + p3; strong alert recall cannot substitute for failed individual hardware-class recall. The predeclared 1% alert-FPR criterion applies to the combined Y in {0,4} population; separate normal/shade FPRs remain visible even when shade-only FPR exceeds 1%.

Explainability uses a class-balanced validation sample rather than test-driven model selection. Coefficients, importance, raw-channel permutations and Tree SHAP describe predictive associations. Deterministic powers and differences are mathematical features, not additional physical sensors. Correlated predictors limit attribution uniqueness; no causal diagnosis or globally optimal sensor set is claimed.
